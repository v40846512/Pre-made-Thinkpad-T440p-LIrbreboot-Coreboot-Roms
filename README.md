# Pre-made-Thinkpad-T440p-LIrbreboot-Coreboot-Roms
Here is where you will find pre-build coreboot and libreboot roms for the thinkpad t440p and more in the future.

Libreboot.rom what payloads does it use?
  It uses grub and seabios as the payloads.
  Intel ME will also be wiped.

Coreboot.rom what payloads does it use?
  Seabios for booting.
  Tint.
  CoreDOOM.
  nvramutil.
  coreinfo.

I hope anyone seeing this enjoys it have fun with your bios modding :)
